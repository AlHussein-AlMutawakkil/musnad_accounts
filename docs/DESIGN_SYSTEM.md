# منظومة التصميم والمكونات المشتركة (Design System)

## 1. الطابع العام (Enterprise / Dense)
واجهات عملية، كثافة بيانات عالية، زوايا مستقيمة خفيفة (`BorderRadius = 4.0`)، حدود رمادية واضحة (`1px`)، وعدم استخدام ظلال مبالغ فيها.

## 2. لوحة الألوان المركزية (`AppColors`)
- **الرئيسي (Primary):** كحلي مؤسسي `#1B365D`
- **الخلفية (Background):** رمادي فاتح محايد `#F4F5F7`
- **البطاقات (Surface):** أبيض نقي `#FFFFFF`
- **له / دائن (Credit):** أخضر معتمد `#1B873F`
- **عليه / مدين (Debit):** أحمر داكن `#C5221F`
- **الحدود (Border):** رمادي دقيق `#E0E0E0`

## 3. مكتبة المكونات المشتركة الملزمة (`core/widgets/`)
يجب استخدام هذه المكونات حصراً ومنع بناء عناصر مخصصة داخل الشاشات:
- **`AppCard`**: حاوية البطاقات ذات الحدود الموحدة.
- **`AppKpiCard`**: بطاقة ملخص مؤشرات المبالغ (له / عليه / الصافي).
- **`AppPrimaryButton` & `AppSecondaryButton`**: أزرار العمليات الرئيسية والإلغاء.
- **`AppFloatingActionButton`**: زر إضافة قيد سريع.
- **`AppTextField` & `AppAmountField`**: حقول الإدخال النصية والمالية ذات الحدود الكاملة.
- **`AppDropdownField` & `AppDatePickerField`**: القوائم المنسدلة والتقويم.
- **`AppTypeToggle`**: زر التبديل المزدوج بين (له) و(عليه).
- **`AppFormattedAmount`**: عرض الأرقام بفواصل الآلاف وتلوين تلقائي (أخضر/أحمر).
- **`AppAccountTile` & `AppTransactionTile`**: صفوف عرض الحسابات والحركات.
- **`AppConfirmDialog` & `AppBottomSheet`**: حوارات التأكيد والأوراق السفلية.
