# تعليمات للذكاء الاصطناعي (AI Prompt Guidelines)

1. اقرأ ملفات `SRS.md` و`ARCHITECTURE.md` و`DESIGN_SYSTEM.md` قبل كتابة أي كود.
2. لا تقفز بين المراحل؛ التزم بالترتيب المحدد في `ROADMAP.md`.
3. لا تكتب كوداً ناقصاً ولا تستخدم تعليقات مثل `// TODO: implement later`؛ اكتب الكود كاملاً وصالحاً للتشغيل.
4. استخدم حصراً المكونات المشتركة المعرفة في `DESIGN_SYSTEM.md` عند بناء الواجهات.
5. تأكد دائماً أن عمليات التحويل والمصارفة تتم داخل معاملة ذرية `db.transaction(...)`.
